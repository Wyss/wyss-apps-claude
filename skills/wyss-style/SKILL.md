# Wyss style: one language for everything we write

Wyss Apps is the record; this is how to talk about what is in it. The same words on the website,
in the Summary by Faculty emails, in the finance reporting kit and in anything Claude writes. When
a term here conflicts with a term in a source document, use this one and note the source's term
once in brackets.

## Say it this way

| Say | Not | Meaning |
|---|---|---|
| **sponsored project** / **grant** | WIGT project, GMAS segment, award | A GMAS record: one funding segment of a sponsored award. Shown in Wyss Apps under *Grants and Sponsored Projects*. Its reference is `SP-YYYY-NNNNN`. |
| **Wyss project** | internal project, WP | A project the Institute runs itself: Director's Fund, validation, platform, institute projects. Reference `WP-YYYY-NNNNN`. |
| **faculty** (Faculty Lead) | owner, professor | The Wyss faculty member who leads the project. Other faculty on a project are *Collaborating Faculty* in its team. |
| **PI** | investigator, lead | The principal investigator GMAS names on a sponsored project. Usually the faculty member, written First Last ("Don Ingber", never "Ingber, Don"). GMAS abbreviates first names; "Don" is Donald Ingber. |
| **maintainer** | owner, editor | The person responsible for keeping a record current. Primary maintainer = one person; additional maintainers edit with the same rights. |
| **team member** | staff, contributor | Someone on the project with a role (Project Lead, Collaborating Faculty, Technical Contributor, Business Development, Finance, Clinical, Mentor Hive, Collaborator, Other). Not the same as a maintainer. |
| **Wyss name** | nickname, short title | The name in daily use for a project. Prefer it over the full title; give the full title once in brackets or a footnote. |
| **status** | state, phase | Sponsored: Pending, Active, Not Funded, Completed, Closed, Cancelled, Terminated (a Wyss override may replace GMAS's). Wyss projects: Not Started, Active, Closed. |
| **funding status** | fundraising | Seeking funding, Not seeking funding, or Stealth (a Wyss project only). |
| **Grand Challenge** | theme, pillar | One of six: Brain Health, Cancer Solutions, Healthy Aging, Infectious Disease Control, Sustainable Futures, Women's Health Innovation. Always the full name, capitalised. |
| **platform initiative** (platform) | lab, group, division | The Wyss technology platform a project belongs to: 3D Organ Engineering, Bioinspired Therapeutics, Diagnostics for Human and Planetary Health, Immuno-Materials, Living Cellular Devices, Molecular Robotics, Synthetic Biology, Sustainable Futures, Nucleic Acid Delivery. The abbreviation (3DOE, BT, DHPH, IM, LCD, MR, SB, SF) only after the full name. |
| **funding source** | funder, bucket | Where a project's money comes from (Validation Project, Northpond DF, Platform / Initiative, DHHS - NIH, NSF, Industry / For Profit, ...). "Sponsored (Grants, Industry Supported)" means external sponsored money. |
| **tag** | label, category | A free-form label editors create; use sparingly in prose. |
| **account** / **account string** | COA, chart string, billing code | The 33-digit Harvard chart-of-accounts string (tub.org.object.fund.activity.subactivity.root). *Fund* is the 6-digit segment people quote. |
| **fiscal year** (FY27) | year | Harvard's year, July 1 to June 30: FY2027 runs 2026-07-01 to 2027-06-30. Write FY27 or FY2027, never "2027" alone for money. |
| **GMAS** | Oracle, the grants system | Harvard's grants management system, the source of sponsored records. |
| **Delphi** | the lake, SQL Server | The HMS data warehouse the transactions and effort come from. |
| **SAB** / **Retreat** | board, offsite | The Scientific Advisory Board; the annual Wyss Retreat. Projects are flagged for inclusion in each. |
| **ROI** / **HU Case #** | patent, IP | Report of Invention (first disclosure); the OTD case number. Say "patent" only for an actual patent or application. |

## Amounts

- Name the amount every time: **proposed** (asked for), **anticipated** (expected to be awarded),
  **obligated** (GMAS says is committed so far), **awarded** (Wyss projects: actual money recorded).
  Never a bare "budget" or "funding" figure.
- Say **direct**, **indirect** or **total** when the split exists. Sponsored totals = direct + indirect.
- USD, no cents in prose ($3.96M, $412,500), two decimals in tables. Thousands separators always.
  Round consistently within one document; say "about" when rounding to millions.
- A sponsored continuation is the next slice of already-awarded money, not new money. "Requested"
  totals count initial, supplement and renewal requests only.
- Wyss projects' dollars are the sum of their funding rows; say which funding source when it matters.
- If Wyss Apps hid the financial section (viewer access), say so; never estimate.

## Dates and names

- Dates: 2026-10-27 in tables and data; "27 October 2026" or "October 27, 2026" in prose, one
  style per document. Quarters as FY27 Q1 (July to September 2026).
- People: First Last. Faculty get no title in running text ("Jennifer Lewis", not "Prof. Lewis")
  unless the document is external. Email addresses only when asked.
- Projects: Wyss name first, full title once if different, reference (WP-/SP-) in tables and
  footnotes, link to the Wyss Apps page when the reader has an account.
- Sponsor names as GMAS writes them, then the common form in brackets the first time
  ("DHHS/National Institutes of Health (NIH)").

## Writing

- Plain sentences, one idea each, present tense for the current state ("The project is Active
  and anticipates $1.2M"). Past tense only for events with dates.
- Lead with the answer, then the evidence from Wyss Apps, then what is missing or hidden.
- Say where a fact came from when it is not obvious: "(GMAS status)", "(Wyss override)",
  "(from the project's Current Status, updated 2026-09-12)".
- Distinguish what a proposal *promised* (abstract, summary) from what the team *reports*
  (Current Status). Never present proposal text as a result.
- Do not invent numbers, names, dates or outcomes. "Not recorded in Wyss Apps" is a complete
  sentence.
- No em dashes; use commas, full stops or brackets. No exclamation marks. British or American
  spelling, one per document (the app uses American).

## Report layout (tables, summaries, emails)

- Title: what, for whom, as of when ("Sponsored projects, Ingber lab, as of 2026-10-27").
- A one-paragraph summary first: counts, totals, what changed.
- Tables: one row per project; column order **Project (Wyss name) · Faculty/PI · Status ·
  Sponsor or Funding source · Amount (named) · Dates**. Sort by status then amount descending
  unless asked. Totals row last. Reference and link in the last column.
- Group by faculty when the audience is leadership (the Summary by Faculty convention), by
  Grand Challenge or platform when the audience is science, by sponsor or fund when it is
  finance.
- Every table says which amount it shows in the header ("Anticipated total, USD").
- End with "Source: Wyss Apps, <date>; <what was excluded>".

## Look (documents, slides, dashboards)

- Colours: Wyss Midnight `#000032` (headings, header rows), Wyss Whale `#0C277E` (links,
  secondary), Wyss Arctic `#1EAFEC` (accents, rules under headings). Grand Challenge colours:
  Brain Health cornflower `#7192EB`, Women's Health Innovation coral `#F96366`, Infectious Disease
  Control terracotta `#9B391E`, Cancer Solutions sea urchin `#564785`, Healthy Aging sunshine
  `#FCB83A` (dark text), Sustainable Futures seaweed `#336252`. Status: Active seaweed, Closed
  gray, Not Started light gray; Seeking funding arctic.
- Type: Graphik for text and UI, Tiempos Headline for titles, Tiempos Text for long documents,
  Degular Mono for codes and ids. Fall back to Helvetica/Georgia/Menlo.
- Shapes: cards with the asymmetric corners (large top-left and bottom-right, small the other
  two). Pills with small radius, not fully round.
- PDF/print: H1 Midnight 22px, H2 Midnight 14px uppercase with an Arctic underline, table header
  Midnight with white text, alternate rows white/gray-50, footer "Wyss Institute" centred with
  the generated date left and page numbers right.
